# MessageLoggerEnhanced v3.5

Adds edited-message support to the main panel.

- All / Deleted / Edited selector
- Before and after text for every edit
- Yellow Edited badge and card border
- Live edited messages receive an Edited marker in chat
- JSON export respects the selected log type and filters
- Existing DM/server tracking controls remain unchanged

Install in `Vencord/src/userplugins/MessageLoggerEnhanced/`, run `pnpm build`, and restart Discord.
